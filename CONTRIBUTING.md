# Contributing

Thank you for your interest in the Nebosvod SDK.

1. Open an issue describing the problem or proposal before large changes.
2. Keep pull requests small and focused; include tests and documentation.
3. Code style: ruff (lint + format), mypy strict, English identifiers and comments.
4. Do not edit `schemas/`; contract changes are made upstream and published automatically.
5. By submitting a contribution you agree that it is licensed under the Apache License 2.0.
